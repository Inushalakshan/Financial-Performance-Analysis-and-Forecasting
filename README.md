# Financial Performance Analysis & Forecasting

## Project Overview
This project analyzes historical financial data using Python and Power BI to evaluate business performance, profitability, financial ratios, and revenue growth.

It also uses historical financial performance to develop a financial forecast.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Power BI
- Jupyter Notebook
- Microsoft Excel / CSV

## Key Analysis

### 1. Data Preparation
- Imported financial datasets using Pandas.
- Checked missing values and data types.
- Cleaned and converted financial columns.

### 2. Financial Statement Analysis
Calculated:
- Gross Profit
- EBITDA
- EBIT
- Profit Before Tax (PBT)
- Tax Expense
- Net Profit

### 3. Financial Ratio Analysis
- Gross Profit Margin
- EBITDA Margin
- EBIT Margin
- Net Profit Margin
- Interest Coverage Ratio

### 4. Growth Analysis
- Revenue Growth
- Net Profit Growth
- EBITDA Growth
- Compound Annual Growth Rate (CAGR)

### 5. Financial Forecasting
Used historical CAGR to estimate future:
- Revenue
- Net Profit
- Cost of Goods Sold (COGS)

### 6. Power BI Dashboard
Developed an interactive dashboard to visualize financial performance, profitability, and business growth.

## Project Outcomes
- Evaluated historical financial performance.
- Identified revenue and profitability trends.
- Analyzed financial ratios.
- Estimated future financial performance.

## Disclaimer
This project uses sample financial data for educational and portfolio purposes. Forecasts are illustrative estimates, not actual financial results.
